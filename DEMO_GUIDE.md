# 3–5-minute Streamlit demo guide

The assignment guidelines request a 3–5-minute front-end demonstration.
Record a screen capture *after* generating the single five-model pickle file.

1. **0:00–0:35 — Project purpose**
   Explain predicting district-season paddy production in tonnes; briefly
   introduce EBM as the interpretable algorithm alongside four benchmarks.
2. **0:35–1:10 — Dashboard**
   Show 660 records, the date range, Maha/Yala filters, and a production chart.
3. **1:10–2:35 — User input and predictions**
   Open Predict Production, select a 2022–2023 sample or enter measurements,
   choose EBM, click Predict, and show the output in tonnes and all five model
   estimates. Explain the observed harvest only appears for existing records.
4. **2:35–3:35 — Prediction explanations**
   Show EBM's positive and negative feature contributions, then demonstrate the
   +10% what-if view, clearly noting this is sensitivity, not causation.
5. **3:35–4:35 — Model Insights and results**
   Show MAE, RMSE, R² comparisons and EBM global importance. Note how the
   validation-selected model differs from the lowest test-error model.
6. **4:35–5:00 — Limitations and close**
   Explain inputs are full-season observations and cannot provide a reliable
   before-sowing forecast. Remind viewers the app is for academic use.

Don't record model-loading errors as the demonstration of working predictions.
